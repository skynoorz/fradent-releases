# Fradent · APKs

Repositorio público **solo con los APKs** de Fradent (agenda del sillón del consultorio).
El código fuente está en un repositorio privado.

La app consulta la última *Release* de este repo para ofrecer actualizaciones:

- `Fradent-X.Y.Z-arm64-v8a.apk`: celulares modernos (más liviano).
- `Fradent-X.Y.Z-universal.apk`: cualquier celular Android.

Las Releases se publican con `dart run tool/publicar.dart` desde el repo del código.
